<objective>
Put the server-side safety controls in place around the paid route: metadata-only request
logging, a guard that refuses requests from other origins, and a small hand-written rate limiter
(D-19, which overrides the research table that names `express-rate-limit`).

Purpose: the server proxies paid AI calls with the user's key and receives the user's resume.
It must not log or store that content, and a web page on another origin must not be able to
make it spend money (DATA-06, DATA-07).

Output: three middleware modules with their tests, wired into `createApp` in a fixed order.
</objective>

The server sends no CORS headers at all and has no CORS middleware: the page reaches the API through the Vite proxy on the same origin, so a browser on another origin is stopped both by its own preflight and by this guard.

    `server/src/http/rate-limit.ts`: export `createRateLimiter({ windowMs = 60000, max = 20, now })`.
