Prove the riskiest path of the phase on the server: an HTTP request goes in, a schema-constrained
call goes out through the real `@google/genai` SDK, and validated per-requirement ratings come
back. In tests the SDK talks to a deterministic stand-in model over HTTP, so the whole path runs
with no key and no network.

Purpose: this is the server half of the walking skeleton. It fixes the wire contracts and the
AI client seam that every later plan builds on (D-01, D-03, D-04, D-15).

over `generateContent`, `POST /api/fit`, the stand-in model, and an end-to-end server test.

none of them. Each file is short; the estimate is well inside the budget.

|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-03 | Information disclosure | `GEMINI_API_KEY` in responses or logs | high | mitigate | Key read only in `config/env.ts`, passed explicitly to the SDK, never logged; test case 8 asserts no response contains the key value |
| T-01-04 | Tampering | Client-supplied model id, prompt or requirement list | high | mitigate | `fitRequestSchema` is a strict object with only `jobId` and `resumeText`; requirements come from the server seed; test case 4 |
| T-01-05 | Information disclosure | Provider-side retention beyond the request | medium | mitigate | `generateContent` only; no Interactions API, no Files API, no tools; test case 2 asserts the request path and the absence of `tools` |
| T-01-06 | Denial of service | Silent paid retries or a hung model call | medium | mitigate | No `retryOptions`; explicit deadline through `AbortSignal.timeout`; test cases 5 and 6 assert one upstream request and a bounded wait |
| T-01-07 | Tampering | Blocked or truncated model output treated as success | high | mitigate | `generateJson` checks block reason, finish reason, empty text, JSON and Zod before returning; test case 5 |
| T-01-08 | Tampering | Prompt injection through resume text | medium | mitigate | Instructions only in the system instruction, resume and job in delimited tags stated to be data, no tools, schema-constrained enums; delimiter neutralisation follows in plan 01-04 and quote verification in plan 01-07 |
| T-01-SC | Tampering | npm installs | high | mitigate | No install in this plan; if one becomes necessary, stop: the package-legitimacy gate and a blocking human checkpoint apply |
</threat_model>
