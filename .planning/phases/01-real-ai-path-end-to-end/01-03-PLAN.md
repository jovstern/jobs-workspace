## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser storage to page | Stored analyses are input from an earlier session and may be tampered with |
| Test runner to API | A browser test could reach a developer's API that holds the real key |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
