<objective>
Make the ratings trustworthy: the model must quote the resume for every met or partial rating,
and the server checks each quote against the text it actually sent. A quote that is not there
turns the rating into not evidenced. Model output is reconciled against the job's fixed
requirement list before it leaves the server.

Purpose: FIT-02 and the project rule that the score rests on verified evidence, never on the
model's word. This is also the main limit on what injected text in a resume can achieve.

Output: the quote verifier, the fit pipeline in its own module, the prompt and model-output
schema in their own module, and a schema converter that sends only supported keywords.
</objective>
