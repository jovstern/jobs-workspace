## Flagged assumptions

- **No way to change a saved resume in this phase.** Replace and delete are RES-04 in Phase 01.2. Until then the only way to change a saved resume is to clear the site's data in the browser. Browser tests start from an empty context, so they are not affected.
- **The pasted text stays editable until it is saved.** The form shows the contact-free text in the same textarea before saving, so the notice sentence "Check the text below for anything else you want to remove" is true. The two-step review dialog and the profile (RES-03) remain Phase 01.2.
- **Two tabs (edge probe: DATA-01 concurrency, backstop).** No cross-tab synchronisation is built. Each write stores a complete, valid record, so the last write wins and neither tab can leave a half-written value. This is recorded as a backstop truth for human confirmation.
- **UI-SPEC considerations not lifted here.** Loading and error states of the intake form, the profile editor, chips and roles describe PDF reading and profile building in Phase 01.2.
