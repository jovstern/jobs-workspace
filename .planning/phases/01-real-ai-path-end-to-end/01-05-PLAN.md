<objective>
Give the user real jobs to check against: nine hand-written seed jobs with their requirement
lists (D-14, D-15), a synthetic demo resume authored together with them so the demo shows both a
near-perfect and a poor fit, and a tidy stub page with a job list and a job detail view.

Purpose: the model rates a fixed, hand-authored requirement list and never invents one; this plan
supplies that list and shows it to the user exactly as it will be rated.

Output: the seed set with pinned ids, the demo resume fixture, three shared presentational
components (Card, Button, Notice) and the JobPicker and JobDetail components.
</objective>
