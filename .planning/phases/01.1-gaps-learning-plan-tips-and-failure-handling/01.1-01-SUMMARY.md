# Phase 01.1 Plan 01: Learning plan per gap Summary

**A fit check now returns a validated learning plan for every gap, built in code from the final ratings, with the model call sized (8192 tokens, 45 s) for the larger answer.**

## Accomplishments

- Shared contract: `learningPlanSchema`, `tailoringSchema`, `adviceSchema` with their limits; the stored `advice` is nullable and the schema version stays 1.
- Prompt `fit-advice-1` with the eight advice rules, a strict wire schema (`ratings`, `plans`, `tailoring`) and a lenient parse schema that only enforces the ratings.
- `buildAdvice` keeps a plan only for a requirement of the job whose final rating is not met, first plan per id wins, emitted in posting order; it cannot throw.
- The stand-in model writes plans and tailoring, plus an `advice_malformed` scenario; routes, analyze, schema, shared and e2e tests cover the new behaviour.
- `MODELS.fit` raised to 8192 output tokens and a 45 s deadline, with a test that pins both against the browser's 60 s timeout; COVERAGE.md records that no new provider capability is used.

## Decisions Made

See key-decisions. The stand-in plans are rule-based: a partial rating gets 2 steps and effort days, not evidenced gets 3 steps and effort weeks.

## Deviations from Plan

None - plan executed exactly as written. One note: the plan's wording starts the tracer with a failing route assertion; as the tracer is a single commit, tests and implementation were written together and the full verify was run before the one commit.

## Issues Encountered

None. The shared plan schema accepts 1 to 4 steps (the 2-step minimum is on the wire schema only), so a one-step plan is kept; the analyze test for over-limit plans uses five steps.

## Known Stubs

Tailoring is always `null` in the response, by design. Plan 01.1-03 adds verified tips and keywords. Nothing in the UI renders from it yet.

## Threat Flags

None. No new endpoint, auth path or storage. Advice is built inside the existing route; `onAdviceStats` passes counts only, is never passed by the route and nothing logs plan text or counts.
