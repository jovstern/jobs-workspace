# Phase 01.1 — Validation Strategy

> Per-phase validation contract for feedback sampling during execution.
> Seeded from `01.1-RESEARCH.md` §Validation Architecture. The planner fills the task ids.

---

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Vitest 5.0.3 (root: jsdom; server: node) and Playwright 1.64.0 (chromium, recorded) |
| **Config file** | root `vite.config.ts` (test block), server default Vitest config, `playwright.config.ts` |
| **Quick run command** | root: `npx vitest run <file>`; server: `npm --prefix server run test -- <file>` |
| **Full suite command** | `npm run check && npm --prefix server run check && npm run e2e` |
| **Estimated runtime** | ~90 seconds for the full suite; a single file is a few seconds |

---

## Sampling Rate

- **After every task commit:** the touched file's quick command; `npm run check` when root code
  changed; `npm --prefix server run check` when server code changed
- **After every plan wave:** `npm run check`, `npm --prefix server run check`, `npm run e2e`
- **Before `/gsd-verify-work`:** all three must be green
- **Max feedback latency:** 120 seconds
