## Pattern Assignments

### `shared/src/error.ts` (contract)
**Analog:** itself, lines 3-30. Add `ai_*` codes to the `ERROR_CODES` tuple. `isKnownErrorCode` derives from it. Keep the wire `code` a plain `z.string()` (line 25) so old clients degrade to the generic message. The shared message table goes here, keyed by `ErrorCode`.
```ts
export const ERROR_CODES = ['ai_not_configured','ai_failed', /* ... */ 'internal_error'] as const
export type ErrorCode = (typeof ERROR_CODES)[number]
```
Also update `shared/src/contracts.test.ts`, which currently asserts `ai_rate_limited` is unknown.

### `server/src/http/errors.ts` (middleware)
**Analog:** itself, lines 11-46. Add one `ERROR_TABLE` entry per new code (`Record<ErrorCode, ErrorShape>` makes the compiler enforce it). Replace the two-way `publicMessage` with a lookup into the shared table. Keep the rule that the message is fixed per code, so no request, resume or model text reaches a response.
```ts
const ERROR_TABLE: Record<ErrorCode, ErrorShape> = {
  ai_failed: { status: 502, retryable: true },
  too_many_requests: { status: 429, retryable: true },
}
export class AppError extends Error {
  constructor(code: ErrorCode) {
    super(publicMessage(code)); this.code = code
    this.status = ERROR_TABLE[code].status; this.retryable = ERROR_TABLE[code].retryable
  }
}
```

## Shared Patterns
- **Error envelope:** `{error:{code,message,retryable}}` from shared `apiErrorSchema`. The server sends a fixed message per code and the client parses it with the shared schema.
- **Privacy:** log route, status and duration only. Never log a resume, request body or model output.
- **Zod at every boundary:** `parseBody`, `fitResponseSchema`, and `safeParse` on persisted state.
- **Model rules:** the score is computed in code, so never ask the model for it. Model ids live only in `server/src/config/models.ts`.
- **UI:** Tailwind utility classes, `Notice`, `Badge`, `Button` and Radix from `radix-ui`. No `new Date()` in render.
